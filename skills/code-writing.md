# Code Writing

This skill teaches the agent how to write good code.

## General Principles

1. **Read before writing**: Always read existing code first to understand patterns
2. **Follow conventions**: Use the same style as existing code
3. **Keep it simple**: Write clear, readable code
4. **Test your work**: Verify that your code works

## Steps for Writing Code

1. Understand the requirement
2. Check if similar code exists
3. Write the code following project conventions
4. Test the code
5. Document if needed

## Common Patterns

- Use TypeScript for type safety
- Follow the project's naming conventions
- Add comments only when necessary
- Handle errors properly

## When Stuck

If you're not sure how to do something:

1. Search for similar code in the project
2. Check documentation
3. Ask the user for clarification
4. Use `search_assets` to find relevant tools or skills
