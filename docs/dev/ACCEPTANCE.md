# Vessel MVP 功能验收表

> 从**用户视角**验收:用户想用 Vessel 做什么,系统能不能帮他做到。
> 每项一个"用户故事",照「怎么做」操作,看「通过标准」是否命中。
> 状态列打勾:`✅ 通过` / `❌ 未通过` / `⚠️ 部分通过`。
> 优先级:`P0`=没有它产品就不可用;`P1`=重要;`P2`=加分项。

## 用户是谁

| 用户 | 特征 | Vessel 给 TA 什么 |
|------|------|------------------|
| **小白用户** | 不懂编程、不配服务器 | 填个 Key 就能聊的终端助手 + 网页控制台 |
| **进阶用户** | 会写简单 YAML | 能改配置、加技能、接外部工具 |
| **开发者** | 会写代码 | 能把核心嵌进自己的程序,做自己的 agent |

---

## 验收环境(先准备好)

```bash
git checkout dev && bun install                      # 后端依赖
cd apps/web && npm install                            # 前端依赖(独立)
```

- **有 API Key**:直接 `bun run src/cli.ts` 起步。
- **没有 Key 想先试**:在命令前加 `VESSEL_MOCK=1`,用模拟模式体验全部功能。

## 一、能不能跑起来聊天(P0)

| # | 用户想做什么 | 怎么做 | 通过标准(看到什么) | 状态 |
|---|-------------|--------|--------------------|------|
| 1.1 | 第一次用,不知道 Key 放哪 | 无配置直接交互启动 `bun run src/cli.ts` | 弹出**引导向导**,一步步教填 API 地址、Key、选模型;填完保存到 `~/.vessel/config.yaml`,以后不用再填 | |
| 1.2 | 在终端和 AI 对话 | `VESSEL_MOCK=1 bun run src/cli.ts` 进入对话界面,输入"你好"回车 | 能输入、能看到 AI 回答,像聊天一样 | |
| 1.3 | 不开终端,命令行一次问一句 | `VESSEL_MOCK=1 bun run src/cli.ts --run "帮我写个冒泡排序"` | 直接打印回答并退出,适合脚本调用 | |
| 1.4 | 用管道喂内容 | `echo "翻译这句话" \| VESSEL_MOCK=1 bun run src/cli.ts --run` | 从管道读到输入并回答 | |
| 1.5 | 想知道有哪些命令 | 交互界面输入 `/help` | 列出所有可用斜杠命令,一看就懂 | |

## 二、能不能看到 AI 在干嘛(P0)

| # | 用户想做什么 | 怎么做 | 通过标准(看到什么) | 状态 |
|---|-------------|--------|--------------------|------|

## 三、关掉后能不能接着聊(P0)

| # | 用户想做什么 | 怎么做 | 通过标准(看到什么) | 状态 |
|---|-------------|--------|--------------------|------|

| 3.3 | 查看历史会话 | `/history` | 列出全部历史会话 | |

## 四、能不能让它干"真活"(工具 + 能力)(P1)

| # | 用户想做什么 | 怎么做 | 通过标准(看到什么) | 状态 |
|---|-------------|--------|--------------------|------|
| 4.1 | 看它有哪些工具 | `/tools` | 列出当前可用的工具清单 | |
| 4.2 | 让它学会新技能(知识/方法) | 放入技能文件后重启,`/skills` | 技能被加载进系统提示;AI 会用技能里的方法做事 | |
| 4.3 | 手动添加/移除技能 | 通过技能管理命令 add/remove | 技能列表实时更新 | |
| 4.4 | 接外部服务(数据库/API) | 配置一个 MCP server,`/mcp` | 能看到 MCP 连接与它提供的工具,AI 能调用 | |
| 4.5 | 让它自己补能力缺口 | 问一个它没有工具的任务(如"查网页") | AI 能意识到缺什么,尝试查资产/建工具,而不是直接说"我不会" | |
| 4.6 | 让 AI 自查资产 | `/assets` | 列出工具/技能/MCP 资产,可查看详情 | |
| 4.7 | 大任务拆给子 AI 干 | 让它"分头调研三个话题再汇总" | AI 调用子任务分派(`delegate_task`),看到 `subagent.` 事件;子任务结果回收;不会无限套娃 | |

| 5.8 | 端口/地址错了能知道 | 故意填错地址 | 明确提示"无法连接",而不是一直转圈 | |
