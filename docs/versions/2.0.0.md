### 破坏性（升级须知）

- **装的插件默认开启（`plugins:` 覆盖层语义）**（用户裁定，q-plugin-default-on）：默认集（全部已安装的 in-process 能力插件，**media 转默认**、`OPT_IN_PLUGINS` 清空）恒为底，`plugins:` 条目只做覆盖——`enabled:false` 排除 / 列入 = 显式启用 / 未列入 = 走默认（新装插件不配置即装载）；旧「完整启用清单」契约作废，`plugins: []` 由空集变为完整默认集，金丝雀 issue-0 部分清单陷阱随之消失。`vessel plugin enable|disable` **不再物化全量清单**（只写目标单条），修复物化名单漂移与「物化后新装插件静默不加载」。**存量配置行为变化**：靠部分清单刻意只开少数插件的配置会开启完整默认集，须 `enabled:false` 显式关——**金丝雀重点回归项**。结构性排除保留（逐个论证见 docs/dev/plans/plugin-default-on-notes.md §2）：provider 类 / 工厂式插件（feishu 凭证安全面、mcp-client 无连接对象、evals 缺省已启用、engine-client 基础设施）/ hook-logging（debug 门控）/ child（宿主 spawn，缺省启用语义不变）。版本位按 RELEASE §1 breaking→minor 由发布收口裁定。

### 新增

- **早退修复 + 无感重试**：tool-calling-loop 空响应 nudge 兜底（限次防死循环）+ `emptyResponse.seamless` 无感重调（空轮发布前丢弃，零疤痕）；设置 `enabled/seamless/maxRetries/nudge` 四路同步（YAML/config.set/CLI/WebUI）。
- **VSCode 式设置（S1–S6）**：可检索弹窗（分类树/搜索 @token/用户·工作区层）+ **插件设置域自动发现**（manifest `contributes.settings` 透传归一化，装上即出现）+ `plugins.config.set` 写 RPC + **默认视觉契约**（系统消息默认隐藏、设置入口右上角齿轮替换 gateway 图标，`specs/default-visual-contract.md`）。
- **federation peer 动态管理 CLI**（`vessel federation peer add/list/remove` 热应用）+ **CLI node targeting**（`--connect`/`--node` 任意 node 建 agent）+ 双舰队接入指南。
- **显示修复**：async bash 完成通知来源归 `tool:bash`（前端「来自 bash」）+ 环境信息增量卡运行中 live 可见（`buildLiveItems` 投影 `message.injected`）。
