# 0.7.0

> 该版本没有独立 CHANGELOG 段；以下来自当时的架构快照（0.7 CLI / TUI 前端对齐）。
> 未 tag、未 `npm publish`、未合并 `main`。

### Added

- **`VESSEL_INDICATOR`**：取值 `unicode | ascii | emoji | kaomoji`，缺省 `unicode`；无效值 / 空值回退 `unicode`。实现为纯函数 `resolveIndicatorStyle`，消费者是 `SpinnerWithVerb`；组件挂载时读取一次，运行中修改需重启 REPL。帧间隔：`unicode` 80ms、`ascii` 100ms、`emoji` 600ms、`kaomoji` 2500ms；只影响 thinking / tool 态前缀，`idle` 固定 `○ idle`。
- **`/details [hidden|collapsed|expanded]`**：默认 `collapsed`；取值写入 `ReplState.toolDetailMode`，只影响当前进程的渲染，不写配置文件。`hidden` 不渲染 trail；`collapsed` 渲染头行 + 最近 1 个工具调用；`expanded` 渲染头行 + 最近至多 8 个（更早折叠为 `…and N earlier`）；非法值回显用法且不改变状态。
- **`ReplContext.version`**：可选字段，由 `src/bootstrap.ts` 注入根 `package.json` 的版本号；TUI 启动头显示 `VESSEL · vX`，缺失时退化为 `VESSEL`，不参与 runtime / RPC 语义。

### 边界

- 只改 CLI / TUI 用户可见接口；runtime / RPC / 插件语义零改动。
- `0.7.1` 是同线 P0 加固补丁，不改变本节语义。

### 状态

- **状态**：CLI / TUI 前端对齐（未随版本发布）；`0.7.1` 为 P0 补丁线（见 [0.7.1](0.7.1.md)）。决策见 ADR-022（spinner）。
