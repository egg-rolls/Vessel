### Added

- **Platform Gateway / Node API 拆分（G1）**：同一进程双监听 8642（平台入口、UI 宿主、
  `platform.*` 只读 RPC）与 8644（公司 runtime、数据面）；平台 token 与 per-node token 分离；
  `vessel gateway` / `vessel node` CLI。合入 `8be78ccf`（tree `1df02f76`）。
- **多本地 Node（G3）**：每个本地 Node 独立子进程，各自 dataDir/config/token；`nodes.json`
  registry（不存 token/端口）；`platform.nodes.credentials({node_id?})`；`gateway nodes list|add|remove`；
  Web 平台模式按 registry 选节点与 per-node token 分槽。合入 `80d93877`（tree `73b7d279`）。
- **Hub 独立 Platform 服务**：Hub 独立进程；仅 node→hub；Hub 持 token broker；删除 hub→node、
  节点入站 `/v1/hub/control`/`/v1/hub/pair`、`auth.*`、`hub pair/node add/token`；保留
  `hub.tokenEnv` / `hub.allowFileSecrets`；内置 Platform Hub 页。合入 `766f9993`（tree `751dfa17`）。
- **tenant 抽象移除（T0–T5）**：单公司单 node；`tenants.*` RPC、`tenant_id` 参数/DTO、
  `vessel tenant`/`--tenant`/`VESSEL_TENANT`、Web Tenants 页、config tenant 块/overlay/quota、
  Hub/federation tenant 绑定均删除；根布局 `<dataDir>/**`；T2 迁移引擎删除，`vessel migrate`
  只保留 0.5 存储格式迁移；`tenant_locked` → `data_locked`（`src/data-lock.ts`），运行时不再
  获取写者锁；`tenant.json` 只读持久化单 id。合入 `e54f7f0f` / `2a7ce827` / `76ae9976` /
  `c1dd8d28` / `d821990d`（T5 tree `4d6eaff6`，80 files +497/−3134）。
- **开发期清库**：`vessel dev reset [--yes] [--dry-run] [--json]` 清空 resolved dataDir 内容
  （保留目录，不动用户 config）；危险根 / 运行中端口 / 顶层符号链接护栏。`fdf510d9`。
