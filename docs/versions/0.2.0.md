# 0.2.0

> 该版本没有独立的 CHANGELOG 段；以下来自当时的版本状态记录。

### 状态

- **状态**：多 agent Kernel（Host / Scheduler / Transport）与模块 subpath exports **已实现**（`release/0.2`，未随版本发布）；`AgentRuntime` 仍是单 agent loop，Host 不重写循环。决策见 [ADR-037](../adr/ADR-037-modular-agent-runtime.md)。

### 分层与模块边界

- **分层**：`Contracts ← Kernel ← Modules ← SDK ← Shells`；`Plugins` 只依赖 Contracts / 公开 API，经 `PluginHost` 运行期 install；依赖方向由 `scripts/check-deps.ts` 检查。
- **Module ≠ Plugin**：Module 是编译期/构造期边界（一个 port 一个实现）；Plugin 仍是唯一运行期扩展机制；不引入 `ModuleHost` / `ModuleRegistry`。
- **Kernel**：`RuntimeHost`（注册 / 生命周期 / 发现）、`AgentHandle`、`RunHandle`、`Scheduler`（FIFO、并发上限默认 1、同成员串行）、`EventBus`（按 agent / run / 前缀过滤）、`Cancellation` / `Limits`（父子取消传播、run / agent 两级限额）。
- **Module / subpath exports**：provider / context / session / policy / transport / observability / kernel 各自的 port 与 `@vessel-agent/core/<port>` 入口；0.2 只在 core 内做 ports & adapters，不拆包；`types/**` 不 import 实现，模块只经 port 交互，禁止反向依赖 `src/**` / `packages/serve` / `plugins/**`。
- **Transport**：0.2 只做 in-process 与 loopback HTTP（绑 `127.0.0.1`，复用 gateway v1 token，禁止 `0.0.0.0`）；0.6 起 `kind` 扩为 `in-process | loopback | remote`，0.22.1 只保留 `in-process`。
- **兼容**：9 接口、`AgentRuntime` 公开面、`RunOptions` / `RunEvent`、事件名、插件机制冻结；`delegate_task` 改为 Host 一次性临时成员，`@vessel-agent/team` 改为持久成员（0.3 移除 `LegacyHostAdapter`）。
- **0.3 平台能力**：durable run（`RunStore` + `resume`，本机 file / memory）、MCP client 插件、显式 opt-in 远程 / TLS；跨节点 agent transport 已于 0.22.1 删除。
