## [0.25.0] - 2026-10-24

> 0.25.0（基于 0.24.1，未发布）：Web 易用性重做与单一 RPC 契约。未 tag、未 publish。

### Added

- **canonical `agents.create|update|close`**（51 → **54**）：批量契约
  `{ agents: [...] }` → `{ results: [...] }`，与输入同序、单条失败隔离；
  `create` 拒绝 team-scoped token，`team_id` 只绑定已存在 Team；
  `update` 改名立即生效，`model` / `system_prompt` 从下一具 Body 生效。
- **节点显示名**：`node.json` 增加 `name`（首次取主机名，`host.node_name` 可覆盖），
  `health.get.node.name` additive 暴露，hub 目录透传；`node_id` 仍是唯一寻址键。
- **Web 对象页 CRUD**：Nodes（搜索 / 添加弹窗含终端命令 / 浏览器连接 / 移除警示）、
  Teams（创建弹窗 / 编辑页 / 归档警示 / 搜索）、Agents（创建 / 编辑 / 关闭 / 搜索）。
- **导航与状态**：编排组顺序 Agents → Teams → Nodes；底部 Status 组（Hub、Gateway）
  带状态点与版本；新增 Gateway 状态页；顶栏搜索框左侧语言切换。
- **共享组件文档** `docs/WEB-UI.md` 与统一的列表 / 卡片 / 搜索 / 状态样式。

### Changed

- Hub 页只保留 hub 自身状态与版本；配对 / join 命令与 Web 连接管理移入 Nodes。
- i18n：Agents=智能体、Teams=团队、Nodes=节点、Hub=面板核心、Gateway=网关。
- 节点列表不再展示 UUID（详情最多一处），同名节点显示去重为 `-1` / `-2`。
- Settings 的额外节点连接管理移除（主 gateway 连接仍在 Settings）。

### 状态

- **状态（canonical agent 生命周期，分支 `0.25-agent-rpc`，未随版本发布）**：新增 canonical `agents.create` / `agents.update` / `agents.close`（permission `write`），方法总数 51 → **54**。三者都是批量契约（`{ agents: [...] }` → `{ results: [...] }`，与输入同序、单条失败隔离；单条 = 单元素数组）。`agents.create` 不允许 team-scoped control token（逐条 `forbidden`），`team_id` 只绑定已存在 Team（经 `TeamControlLike.get` 解析 workspace，不隐式创建，绑定需要 `name`）；`agents.update` / `agents.close` 的 team-scoped token 只能操作同 team 成员（否则逐条 `not_found`）。`AgentService.update` 改名立即生效（同 Team present 唯一，unbound 为 tenant 唯一），`model` / `systemPrompt` 只写入记录、下一次 spawn 的 Body 才使用（结果带 `applies_to: 'next_body'`），service 发 `agent.updated` 只带字段名。gateway 只依赖结构化 `AgentControlLike`，owner 端点收口为后续工作流。决策见 [ADR-091 Addendum](../adr/ADR-091-agent-body-and-presence.md)。
- **Web 状态（易用性重做，分支 `0.25-web-shell` / `0.25-web-domains`，未随版本发布）**：编排组顺序固定 Agents → Teams → Nodes；底部 Status 组放 Hub（面板核心）与 Gateway（网关），各显示状态点与版本；新增 `#/gateway` 状态页，Hub 页只保留自身状态。Nodes 承担添加节点（终端配对 / join 命令 + 浏览器连接与 token）与移除；Teams 承担创建（弹窗）/ 编辑（页面）/ 归档（警示）；Agents 承担 create（弹窗）/ edit（页面）/ close（警示）并复用 canonical `agents.*`。列表统一支持按名字 / ID 搜索；节点显示名由 `health.get.node.name` 提供，UI 不展示 UUID，同名显示去重为 `-1` / `-2`。i18n：Agents=智能体、Teams=团队、Nodes=节点、Hub=面板核心、Gateway=网关；顶栏搜索框左侧有语言切换。共享组件与间距见 `docs/WEB-UI.md`。
- **状态（节点显示名，分支 `0.25-node-name`，未随版本发布）**：`<dataDir>/node.json` additive 增加 `name`（展示名；`node_id` 仍是唯一寻址 / 去重键）；首次创建用 sanitized `os.hostname()`（trim / 去控制字符 / 折叠空白 / 上限 64，空回退 `node`），旧文件缺 `name` 只在读取时派生、不回写；新增可选 `host.node_name`（优先级 config > node.json > hostname，配置优先只比较告警、不改写），`name` 缺失或非法只回退 hostname（不触发 `node_identity_corrupt`）；`health.get` 的 `node.name` 为必需字符串（未注入时回退 `node_id`），hub 目录 / snapshot 帧 additive 携带 `name`。canonical 仍 **51**，hub 协议版本不变。
