## [0.48.0] - 2026-11-08

> 0.48 开发线（未发布）：插件扩展面 v2 —— manifest 声明 + config 授权的 HTTP / CLI /
> WS 扩展点，插件面只注册在 Node API；外部插件显式 `expose`；catalog 提供
> declared / effective 两视图。状态：**merged**（`main @ a2c999a3`）；未 tag、未 publish。

### Added

- **M1 插件 HTTP**：`contributes.http`（id/method/path/auth/scope/responseMode/限额）；
  serve 纯路由表 + loopback 反代；客户端 header 剥离、响应 header allowlist；
  `plugin.activate` 返回 `httpEndpoint` 并每次 spawn 轮换；disabled 404 / invalid 503。
  合入 `c258448c` / `9c09b9ce`。
- **M2 插件 CLI**：`contributes.cli`（path/description/args/handler）；`parseArgs` 前预解析，
  内置命令优先；args JSON Schema 子集；非法 exit 2；gateway 不在 → `gateway_unavailable`；
  stdout 64 KiB 截断。合入 `86a77578`。
- **M3 插件 WS/流式**：WS/upgrade 帧桥（1009/1013/1001/1011）、限额/背压/idle/生命周期；
  插件面归属 Node API。合入 `a2c999a3`。
- **M4 外部 expose / catalog 两视图**：外部插件显式 `expose` 授权；catalog
  `declaredSurface` / `effectiveSurface`；own-namespace `/plugins/<own-id>/...` carve-out；
  HTTP/CLI 授权各只有一处谓词；审计不写 token/正文。合入 `a2c999a3`。

### 未做 / 已知限制

- **service 生命周期不进 0.48**（`DECISION-052`）；插件 HTTP 多租户方案被 0.49 tenant
  移除取代（`DECISION-053`）。
- M1：OPTIONS 被 CORS 预检先处理；流式 idle 中断为截断 chunked；loopback 检查 best-effort；
  `maxConnections` per-gateway；`plugin-loader` 未传 `reservedHttpRoutes`（运行时已拒绝）。
- M2：`plugin.cli.invoke` 审计只写 debug stderr；`additionalProperties: true` 接受未知 key。
- M3/M4：Bun 1.3.9 客户端 close reason 丢弃；local/bootstrap 的 expose 不随 config watcher
  热刷新；Marketplace declared/effective 浏览器走查未做。
