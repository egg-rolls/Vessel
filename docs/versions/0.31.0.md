## [0.31.0] - 2026-10-31

> 0.31.0（基于 0.30.0，未发布）：Chat 缺陷修复、热应用降级与 body 热重载、Web IA 收敛、
> 限额与阈值调整、rotate 权限确认。7 个提交、40 文件 +819/−501。未 tag、未 publish。

### Added

- **Body 热重载**：reload 后在同一具 body 上重做工具/权限快照（`refreshTools`），
  session / epoch / 上下文不变；有 active run 时延迟到 turn 边界应用。
- **rotate 权限确认**：模型发起的 rotate 一律走既有 permission / ask bridge，
  确认卡带上下文比例；`<90%` 提示通常不需要、`≥90%` 建议换；拒绝或无人类通道
  （headless / feishu 非 TTY）返回 `rotate_not_needed` 且 fail-closed。
  owner / CLI rotate 行为不变；请求、批准、拒绝都有可见事件。
- **Web IA**：团队成员面板收敛到 agents 域，旧深链重定向；智能体页改为响应式卡片网格，
  去掉落单的「打开成员」按钮，点卡片即打开成员。

### Changed

- **删除 `limits.toolCallsLimit`（breaking config）**：工具调用次数不再有软预算；
  循环仍由 `max_iterations` 与 `max_runtime_seconds` 兜底。旧配置带该键仍可加载，但不再生效。
- **上下文阈值**：提示线 0.8 → 0.9；自动压缩 0.9 → 0.95；temporary body 的
  `ROLE_COMPACT_THRESHOLD` 同步 0.95。
- **用户面术语**：Body / epoch → 会话 / 第 N 次会话（wire 字段 `body_id` / `body_history` /
  `epoch` 不变）。

### Fixed

- **热应用不再抛 `tools_hot_apply_unsupported`**：`TenantToolHost` 转发 `unregisterTool`；
  无注销能力时降级为保留旧定义并提示 `restart to remove`；reload 各 scope 隔离，
  一个 applier 失败不再中断其余 scope。
- **Chat 三缺陷**：新会话首次发送缺少 `session_id`；Stop 用成员 id / session id 调 cancel
  导致 `not_found`；队列占位被 `agent.queue.entered` 提前移除（30–60ms 瞬闪）。

### 验证

- 无自动化测试套件（宪法第四条：零测试文件）；每切片用一次性探针红绿验证，探针不提交。
- rotate 探针 10 PASS + 独立复验 39 PASS（含 canConfirm、0.94/0.96 阈值、owner/CLI 直连、
  事件可见）；热重载探针 P1–P5 红→绿；限额探针 6 FAIL→10 PASS。
- 每片合并后根 typecheck、biome、web tsc、web build、mock smoke 全 exit 0。
- 0.30 的 5 域 Web 回归结果仍有效（chat / runs / observe / shell / team，0 个 0.30 回归）。

### 已知边界

- **bash 绕过**：模型可经 `bash` 直接调本地 CLI owner 端点执行 rotate，绕过权限确认；
  这是 `bash` 非沙箱的既有边界，属下一轮安全设计。
- **bridge latent**：宿主若在 `humanApproval=true` 时自行安装 `auto_allow` policy，
  bridge 可能丢应答并等待；当前无 live 路径。
- **收件箱/排队消息持久化未做**：移入 0.32 上下文管理系统周期。
- **headless ask 异步队列未做**：建议单独开「人类通道」周期。

### Not building

- 不恢复工具次数上限；不做自动 rotate；不新增 RPC / 收件箱展示；不新增测试文件。
