### 0.50 收口追加（2026-11-12）

- **事件可见性**：两张黑名单 → 三档白名单（`content`/`internal`/`observe`，114 条），
  未登记类型折叠成 notice；门禁 `check:event-visibility`（含影子对拍）。
- **时间线**：`LiveItemStore` 物化 item（渲染不再读事件缓冲）+ `ClaimLedger` 认领账本 +
  交棒释放；删 `coalesceDelta` / `truncatedSince` / `group-cache.ts`；缓冲裁剪不再让
  屏上内容消失（顺便根治「结尾正文重复」）。
- **回放**：固定 1 MiB → 按「最新一轮地板」动态（实测 4 个真实会话覆盖率 47%→100%），
  门禁 `check:replay-budget`。
- **等待消息**：inbox 条目加 `session_id`/`refs`；待处理条带改读盘（删时间线排队卡）；
  `agents.recall`；**启动即扫恢复孤儿输入**（重启不再丢排队消息）；修 `runs.cancel` 后
  `queuedRuns` 永不清导致 agent 不被 wake 的僵尸 bug。
- **上下文用量**：`sessions.get.context_usage`（尾窗派生 + 水位缓存）；`llm.request`
  落盘 `context_max`；用量环随比例连续变色（60–80 转琥珀、80–90 转危险），`plugin-ui`
  补 `--amber` 三主题档。
- **模型可见性**：`prompt.system_context` 事件（hash 去重）+ 会话页「模型上下文」可展开卡 +
  `sessions.get.system_context`（刷新/重启后仍可见）；`llm.request` 发布副本带 `model`，
  删掉「从 Self Card 抠 model」的死代码。
- **`ask` 工具**：`ask_user` → `ask` + 重写描述（任何需要人说一句的场景），读侧双认旧名；
  `ui.askUser` / `ask:answer` / `ask.user.*` 未动。
- **用量插件**：trace 增量追读 → **数据源换到会话日志 + 持久化索引** + worker 线程聚合 +
  取消硬截断（「全部时间」不再采样）；`logs` 加 `days`/`since-until` 半开区间 + 游标分页 +
  默认 7 天。
- **设计实验室**：token 运行时枚举 + `*.preview.tsx` 自动发现 + 变体表运行时化
  （加 token/组件/变体都只改一处）；颜色 token 固定左亮右暗。
- **导航**：四档状态色统一（accent/amber/danger/muted，删 ok/warn）；插件宿主 `inactive`
  不再误判为断开；Hub 打开即自动探测。
- **构建/DX**：`gateway start` 就地自修复 dist；拆 react-vendor/plugin-ui chunk
  （无 500kB 警告）；种子 `appendMany`（0.81s→0.008s）；`listRich` mtime 缓存
  （19.3ms→1.95ms）；**移除 GitHub CI**（`bun run gates` 成唯一门禁，`release.yml` 的 CD
  保留）；输入框整块 `cursor: text`；思考卡复制/时间改 hover+键盘聚焦显示。

### 已知限制（0.50）

- 用量页 43% 历史请求缺 `llm.request`（模型不可知 ⇒ 成本 unpriced）。
- `prompt.system_context` 只回最近一条；TUI 不渲染该事件、也答不了 async ask。
- `[refs]` 尾注列全动作集但 schema 只含可用 action。
- Hub 自动连接的 Web 端只认缺省 8643；自定义 `hub.listen.port` 仍需手填。
  adopt 的手工 Hub 若未放行平台 Origin，Web 自动连会 403 并回表单。
- Team 成员搜索只覆盖已加载窗口（`members_limit` 100）；超出的成员需继续加载。
- 存量按 cwd 建的旧 Team 不自动删除/迁移；升级后保留并新增 `<dataDir>/default`。
- Team 列表宽度 220–420；暗色表头/内容互换仅在暗色生效，亮色不变。
- G4 分布式 / G5 清理未排期；tenant 残留 cat2/cat3 见 `tenant-id-residual.tsv`；
  浏览器 14 条目视走查仍需用户完成。
