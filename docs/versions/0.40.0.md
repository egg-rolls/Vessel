### Added

- **i18n 孤儿检测（I5）**：`bun run scripts/check-i18n.ts` 新增 I5 —— catalog 里有、
  `apps/web/src/**` 零引用的 key。默认只往 stderr 打一行 warn、不改退出码；`--orphans`
  输出「总数 + 按前缀分组 + 明细 + 待人工确认」。引用判定宁宽勿窄：任意位置的 key 字面量
  （含 key 映射表、`labelKey()` 返回值）都算引用，`t()` 模板按静态前缀 / 后缀命中（沿用 I3
  的前缀口径），形如 `'a.b.'` 的拼接前缀算引用；源码注释先抹除再扫。静态不可解的动态调用点
  （`t(variable)`、空前缀模板）单列，按词元配对进「待人工确认」，不计成孤儿。

### Changed

- **biome 覆盖边界**：`biome.json` 的 `files.includes` 显式排除 `**/*.md` —— markdown 排版归
  `scripts/check-docs.ts`（行数上限、frontmatter、链接、INDEX），biome 只管代码与配置，
  避免两套格式化器对同一批文件各写一套规则。这是**范围界定，不是还债**（缺省配置下 biome 2.5.15
  本来就不处理 markdown；排除是为了防止将来升级后被 Markdown formatter 接管、把 `check-docs`
  的行数上限打红）。
- **文档行数门禁转绿（0.39 已完成，非本批改动）**：`docs/architecture/gateway.md` 101 → 100 行
  （ef83a137）、`gateway-rpc.md` 103@dda00a5f → 98@1f7da374 → 99@ef83a137，
  `bun run scripts/check-docs.ts` exit 0。本批（0.33-gov-gates）未改这两份文件；
  端点表格、ADR 编号、0.39 的方法表与删除面均保留。
- **I5 口径定案**：1 裁决为常驻 warn（只提醒数量、不改退出码）；转 error 需等孤儿清零或
  剩余项全部白名单化后重新裁决。
- **版本号未 bump**：manifest 仍是 `0.33.0`、`CHANGELOG.md` 未动（半 bump 会让两者不一致，
  且 `version.ts --check 0.40.0` 当前即 exit 1）。0.40 只是**线名 + 档案**：收口时由 1 跑一次

### 已知边界

- **I5 的结构性盲区**：helper 里拼出来的 key 不算引用（案例 `role.ts` 的 `roleLabelKey()` 只返回
  `team.role.${role}`，不在 `t()` 实参位置），于是 `team.role.member` / `team.role.temporary`
  被静默判成孤儿，而 `roleOf()` 两个值都会返回 —— **删任一个侧栏就显示裸键**。
  1 已裁决不加白名单、接受这点误差（常驻 warn）；改规则属口径变更，须重新裁决。
- **孤儿处置归 web 线**：`bf7d6c0c` 删 `settings.multinode.*` 13 + `nodes.*` 19、`3bdc06ce` 再删 42 个；
  在 `0.33-web-p1@ca639ff7` 复测 catalog **1316** 键、**孤儿 2**，即上一条那两个动态拼接 key，
  必须保留（预期值就是 2，任何报 0 或 1 的读数都该先按报告第 6 节的命令复现）。gov 分支不碰 catalog。
- 39 处 `t(variable)` / 空前缀模板调用点无法静态校验，是孤儿结论的残余风险面；每轮 I5 都重列。
- `biome ci`（2.5.15）：`main` 基线 **3 个 warning**（`chat.css:555` / `:601` 2×
  `noDescendingSpecificity`、`basic-tools/src/index.ts:284` 1× `noTemplateCurlyInString`）。
  web 线 `862b698c` 修掉前两条、ext 线 `ca639ff7` 豁免后一条，**`feat/egg-webui-ux-align` 上实测
  0 warning / 0 error**（Checked 787 files）；core / tui 全程零 warning。
- catalog 只有 `apps/web` 一个消费方；TUI 有自己的一套 key 空间，两者不共享。
- markdown 排版无自动化门禁：`check-docs` 只查 frontmatter / 行数 / 链接 / INDEX，不校验排版。
- `.github/workflows/release.yml` 里 `- 'v*'` 在 biome 2.6.x 看来该写成 `"v*"`（2.5.15 不检查
  YAML）；升级 biome 前需一并处理，否则 CI 会新增 1 个 format error。
