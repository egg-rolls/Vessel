## [0.32.0] - 2026-10-31

> 0.32.0（基于 0.31.0，未发布）：上下文管理系统。持久化收件箱、模型驱动读取、rotate 顺序、
> 压缩可恢复、可观测、紧急打断。7 个提交、34 文件 +1826/−117。未 tag、未 publish。

### Added

- **持久化收件箱**：按 `agent_id` 存于 `<dataDir>/tenants/<tenant>/inbox/<agent_id>.json`，
  `atomicWrite`/0600/单写者；上限可配置 `agent.inbox_max_messages`（默认 200，按最旧裁剪）。
  消息有稳定 `id`、写入时计算的 `summary`（前 160 字）与 `important` 标记。
- **模型驱动读取**：`inbox` 工具（`list` / `read`）；`list` 返回未读数 + id/ts/source/summary/important，
  `read` 按 ids 或 limit 取原文并标 consumed。取多少、取哪条由模型决定，不自动注入正文。
- **未读提示**：BeforeLlm 只发一条 `[inbox] N unread … use the inbox tool`，并同步
  `runtime.notice`；按未读 id 集合去重，新消息到达才再提示。
- **紧急打断**：`agents.send` 新增可选 `{interrupt, message_id, important}`；打断 = 取消当前
  active run（reason `interrupt`）→ 指定消息优先于旧队列投递。旧队列保持原序、每条只投一次。
- **只读 CLI**：`vessel agent inbox <agent> [--json]` 列 id/summary/important/status；
  `vessel agent send --interrupt [--message-id <id>] [--important]`。
- **压缩可恢复**：压缩应用后发 `message.compaction` 事件（摘要 + removed/kept/remaining/reason）；
  `projectMessages` 可按事件重建，session cache 只做加速。
- **可观测**：TUI / Web 把 `context.pressure` / `context.compacted` / `agent.rotating|rotated`
  渲染为 notice（不再落原始事件卡）；`agents.tree` 输出真实的 `context_used`
  （来自 `context.changed.token_count`），`context_max` 仅在收到 pressure 后填。

### Changed

- **rotate 顺序**：启动嘱托 → 旧队列 → rotate 期间新入队；写前日志先落 inbox 再清内存队列。
- **retire 清理**：旧 body 的 pending notice 清空、`waiting_permission` 取消、hook 关闭，避免串味。
- **limit warning 不再双投递**：只保留 core 的当轮 `vessel:limit`。
- **不再自动插入消息**：投递改由模型通过 `inbox` 工具按需读取。

### Fixed

- rotate / busy / 重启导致排队消息静默丢失。
- rotate 期间消息排到启动嘱托之前。
- 旧 body 权限请求挂死、pendingNotices 串味。
- startup admit / delivery 失败静默（改为开放事件）。
- Web 会话头上下文水位没有真实 producer。

### 验证

- 无自动化测试套件（宪法第四条）；一次性探针：
  收件箱 store/rotate/restart/retire/config 5 项、打断 49 项、压缩重建、可观测红绿、context_used 红绿。
- 每片合并后根 typecheck、biome、web tsc、web build、mock smoke、check-docs / check-rpc 全 exit 0。

### 已知边界

- 读取即 consumed（at-most-once）：read 返回后请求失败不回滚；不引入 ack / 两阶段提交。
- rotate 窗口内投递返回的合成 `run_id` 不可查询（窗口极短）。
- `inbox` 工具绕过 tenant allow/deny（只读本地队列，恒 allow）；`read` 无参默认 20。
- 打断期间 rotate 被拒绝；`important` 只做标记，不改变调度（除显式 interrupt）。
- headless ask 异步队列仍未做，建议单独开「人类通道」周期。

### Not building

- 不做 SQLite / FTS / 向量库、收件箱 Web 页、新 RPC、轮询守护、消息优先级系统。
- 不做自动 rotate、跨会话回忆、压缩后自动重灌文件正文。
- 不新增测试文件。
