## [0.30.0] - 2026-10-31

> 0.30.0（基于 0.29.0，未发布）：Web 产物自愈、Tasks 面退场、诊断页补齐、Web 大文件拆分。
> 14 个提交、95 文件 +8853/−6993。未 tag、未 publish。

### Added

- **Web 产物自愈**：gateway 启动时比较 `apps/web/dist` 与 `apps/web/src` 的修改时间；
  产物落后时**不阻塞**启动，在后台重建，下一次请求就读到新产物。构建把指纹写进两处——
  bundle 内的 `__VESSEL_WEB_BUILD__` 与 `dist/build.json` 的 `builtAt`——已打开的页面
  轮询比对，不一致时显示「刷新」提示条。拉不到 `build.json`（旧产物 / fetch 失败 /
  vite dev）时保持静默：拉不到不等于过期。
- **诊断页补齐**：Observe 诊断页新增 runtime、MCP、plugins、config sources 四块；
  `health.get` 透传 `wait_reason`（core `WaitReason` → run-control → gateway），
  queued 行可直接看到等待原因；复用既有 `mcp.list` / `plugins.list` / `capabilities.list`，
  不新增 RPC。

### Changed

- **Tasks 面退场（breaking）**：删除 Web 的 Tasks 页与 `tasks.list` / `tasks.get` RPC，
  以及只服务它的 `AgentTaskEntry`、`AgentRegistryEntry.delegate`、`state/tasks`。
  canonical 方法表与 `scripts/check-rpc-methods.ts` 同步收缩；`gateway-rpc.md` 已更新。
- **Web 大文件拆分**：10 个 >500 行逻辑文件（合计 7846 行）按域拆成
  容器 + 同目录 hooks/子视图，**导入路径与导出面不变**，全部为纯搬移：
  - `gateway/types.ts` 814 → 6 个域文件 + 15 行 barrel（79/79 导出一致）。
  - `gateway/client.ts` 1025 → 抽象类链 + `client/*`，最大文件 363。
  - `ObserveView` 685→78、`IntegrationsView` 611→75（面板拆出）。
  - `RunsView` 752→236、`RunDetail` 603→282、`MemberDetail` 667→249。
  - `ConnectionProvider` 677→255（9 个私有模块）。
  - `ChatView` 1387→337（4 个 hook + 子视图）；`AppShell` 624→381。
  - 全 web 最大逻辑文件降至 550 行（i18n 文案表除外）。

### Fixed

- **运行时长不再增长**：已结束 run 的时长取终态时间，不随刷新继续走；去掉重复的 tenant chip。
- **未启用的渠道显示为未启用**：飞书 / MCP 面板把 `not_found`、`channel_disabled`、
  `forbidden`、`mcp_disabled` 映射到「未启用」，不再画成「加载失败 + 重试」。
- **切 tab 重置滚动**：Observe、Runs、Settings、Integrations 的路由级滚动容器在切 tab 时
  `scrollTo({top:0})`，长表格的 sticky 表头不再压住 tab 栏。
- **飞书能力位不再虚报**：`hello.features` 只在 default tenant 实际解析到渠道时才含
  `feishu`，不再因为注入了 `feishuFor` 就宣称可用；非 default tenant 仍按请求走
  `feishuForTenant`。
