# 0.6.1

> 该版本没有独立 CHANGELOG 段；以下来自当时的架构快照（0.6.1 对标修复）。
> 未 tag、未 `npm publish`、未合并 `main`。

### 修复

- **多租户会话隔离**：file 分支的 `createSessionBackend` 也传 `{ tenantId }`；`FileSessionBackend.delete()` 在 tenant 模式先 `load()` 再 `isForeign()`，foreign 会话 no-op；显式 `session.storage_path` 越出 tenant 目录只 warn。
- **durable / team 控制面**：`handleDurable` 按 principal 的 tenant 过滤；非 default tenant 无 per-tenant store 返回 `forbidden`；resume 要求 `write`；team REST 复用 `ROLE_RANK`（GET read，spawn / send / cancel / close write / admin）。
- **CLI**：新增 `-c/--continue` 与 `-r/--resume [id]`；`-r` 不再是 `--run` 的短别名；冲突参数在解析期报错。
- **配置与插件**：`permission.auto_approve`；`Plugin.install(host, { config })`；插件来源 `repo → project → user → node_modules`，启动扫描一次；`vessel plugin list|install|remove`；env 覆盖 `VESSEL_PLUGINS` / `VESSEL_SESSION_BACKEND` / `VESSEL_MODEL`；显式列表全 `enabled: false` 不回退全部。
- **运行时 / TUI**：可注入 summarizer 与 `autoCompact`；Guardrail 阻断折回 tool error；provider 对 429 / 5xx / 网络错误做 3 次指数退避；工具消费 `AbortSignal`；`ToolDefinition.concurrencySafe`；`finish_reason === 'stop'` 但有 `tool_calls` 仍进工具轮；`HookResult` / `HookContext`；TUI diff 渲染、Ctrl+O、`/compact` `/context`、输入历史、`/permissions`。
- **Web**：助手文本 Markdown 渲染；`sessions.search`（`{ query, limit? }` → `{ sessions: [...] }`，title / preview / id 优先，snippet 取命中前后各 60 字符）；工具事件带 `args` / `result`（8 KiB 截断）；会话时间分组。
- **跨节点**：事件回灌丢弃本机 `node_id` 帧；远端 `team_spawn` 复用 `buildChildHost` 并传 member limits。
- **扩展**：MCP client 增加 `resources/list|read` 与 prompts 列表；basic-tools 超大结果落盘到 `VESSEL_TOOL_OUTPUT_DIR` 的 per-session 子目录。

### 状态

- **状态**：0.6.1 对标修复（未随版本发布）。决策见 ADR-048（`sessions.search`）、ADR-005 / ADR-029（配置与交互）。
