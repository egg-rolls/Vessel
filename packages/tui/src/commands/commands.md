# REPL 斜杠命令（扁平结构）

所有命令均为顶层，`/<command> [args]` 直接执行。

## 会话管理

| 命令 | 说明 |
|------|------|
| `/sessions` | 列出所有会话（带编号） |
| `/resume [N\|id]` | 恢复会话。无参=显示选择列表，下一行输入编号；N=按编号恢复；id=按 ID 恢复 |
| `/new` | 开启新会话（丢弃当前空会话） |
| `/history` | 显示当前会话的对话历史 |
| `/delete [N\|id]` | 删除会话。无参=显示选择列表，下一行输入编号；N=按编号删除；id=按 ID 删除 |

## 工具

| 命令 | 说明 |
|------|------|
| `/tools` | 列出已注册工具 |

## 系统

| 命令 | 说明 |
|------|------|
| `/help` | 显示可用命令 |
| `/clear` | 清屏 |
| `/setup` | 重新运行首启配置向导 |
| `/reload` | 重新加载配置（不重启） |
| `/exit` | 退出 REPL |
